# REALIZA-18 — SDR

## Sensibilidade

A roda é **autorretrato íntimo de menor** (saúde, família, emocional,
finanças) — a issue mesmo marca "dados sensíveis de menor — visibilidade a
definir". O overlay não amplia coleta, mas **amplia o poder de leitura**:
o delta mostra movimento, que é mais revelador que cada foto isolada.

## Ameaças específicas

- **Reidentificação em relatório público**: se o overlay um dia entrar em
  resumo público/export, precisa anonimizar — fora de escopo aqui; proibido
  expor delta nominal em superfície pública (alinhado com REALIZA-170
  agregações thresholdadas).
- **Estigmatização**: delta negativo exibido sem contexto — copy cuida
  ("evoluiu/não é ranking"); sem cores semáforo verde/vermelho por eixo.
