## Áudio 1: lançamento para mentores

- Criar um "cardzinho" no Claude, como se fosse um kit de lançamento, com o
  vídeo dentro
- Usar o projeto "gestão de comunidades" dentro do Claude, que já tem a
  identidade verbal do Realiza
- Mostrar o vídeo ao Claude para montar um lançamento "bem parrudo"
- Mostrar a visão do mentor: quem é profissional e usa o sistema pode gravar
  com Loom
- Sequência: vídeo primeiro → dá um tempo → mensagem com link do tutorial →
  postar nos grupos de mentores

## Áudio 2: lançamento para mentorados

- Mesma coisa para os alunos: outra abordagem, tutorial próprio (o que eles
  vão fazer, conectar agenda), um vídeozinho, lançar nos grupos
- Lançamento em três passos: cadastrar a conta → fazer login → atualizar o
  perfil e registrar os encontros (isso para os mentores)
- Para os mentorados é basicamente entrar e fazer login: o registro quem
  faz é o mentor
- Depois: ver um "mimo" para comprar e mandar para a casa da galera, algo
  que tenha a ver com a plataforma
